# GPU Intel (iGPU/dGPU)

Dla porównań międzyarchitektonicznych używamy backendu `OpenCL`, który działa na Intel iGPU/dGPU,
NVIDIA i AMD.

Skorzystaj z:
- `gpu/opencl/benchmarks/run_opencl_bandwidth.py`
- `gpu/opencl/benchmarks/run_opencl_compute_fma.py`
- `gpu/opencl/benchmarks/run_opencl_compute_fma_peak.py`

Folder `gpu/intel` zostaje jako placeholder, jeśli zechcesz mieć specyficzny backend Intela.
