# CPU AMD

Ten folder zawiera aliasy benchmarków CPU, które uruchamiają wspólne skrypty z `cpu/benchmarks`.

Użycie:
- `python3 cpu/amd/benchmarks/run_stream.py`
- `python3 cpu/amd/benchmarks/run_compute_fma.py`
- lub pełny zestaw: `python3 run_all_cpu_benchmarks.py`

Pliki CSV i podsumowania pozostają wspólne (data/cpu).
